# harshil-builds.github.io

My personal portfolio site.

**Live:** https://harshil-builds.github.io/

## About

A single-page site built with plain HTML, CSS, and JavaScript — no build step, no dependencies. Styled after the [Astro Cactus](https://github.com/chrismwilliams/astro-theme-cactus) theme, with a monospace, terminal-inspired look and a dark/light toggle that follows your system theme and remembers your choice. It also prints cleanly to PDF.

It covers my experience, projects, skills, and education.

## Running locally

```bash
git clone https://github.com/harshil-builds/harshil-builds.github.io.git
cd harshil-builds.github.io
python3 -m http.server 8000
```

Then visit http://localhost:8000. Since it's a single static file, you can also just open `index.html` directly in your browser.

## Editing

Everything lives in `index.html`. Edit the section you want to change, then commit and push — GitHub Pages redeploys automatically.
